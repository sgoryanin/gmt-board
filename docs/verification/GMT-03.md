## Ограничения живой проверки

- **SKIPPED_ENVIRONMENT: Escape непосредственно во время drag.** API выполняет весь жест очень быстро. Параллельная отправка Escape не попала в удержание; затем синхронизация по видимому tooltip истекла по timeout, поскольку tooltip уже был скрыт после отпускания. Этот timeout не считается PASS и не является обнаруженным дефектом приложения. Код отмены/освобождения capture/RAF независимо проверен.
- **SKIPPED_ENVIRONMENT: длительное удержание у края для автопрокрутки и визуальный снимок активного preview.** API не предоставляет отдельные mouse-down/move/up или паузу внутри drag. Чтение DOM параллельно жесту не захватило активный preview. Реальные переносы после обычной прокрутки и отказ на правой границе проверены; длительная автопрокрутка, Escape и очистка при потере capture подтверждены только код-ревью, без заявления о live PASS.

Это дополнительные проверки удержания; основной путь контрольной точки A (назначить → перенести → снять → восстановить) прошёл вживую. При появлении подходящего браузерного управления повторить именно пропущенные проверки; не перезапускать весь набор без причины.

Начальная ошибка старой привязки Computer Use `browser.user is unavailable` устранена сбросом REPL и привязкой той же вкладки. Во время очистки один locator-клик не открыл карточку из-за sticky-перекрытия; причина найдена чтением геометрии/elementFromPoint, исправление описано выше. Одна первоначальная цель «обед» фактически соответствовала 12:45 и корректно была принята; после пересчёта координат проверена именно 12:00, отказ получен. Неудачные попытки не выдаются за успешные проверки.
